### Sistemas Operativos

Kernel Lab organiza el temario de los capítulos **4 y 5 de Sistemas Operativos Modernos** y **3, 4, 7 y 13 de Sistema Operativo Linux**. Incluye:

- Simuladores gráficos de archivos, inodos, asignación de bloques, entrada/salida, permisos y estructuras de control.
- Una consola guiada para comandos básicos y un entorno Linux real externo, integrado mediante JSLinux, para ejecutar Bash.
- Preguntas con explicación, tarjetas de memoria y repaso de errores.
- Un simulacro con **10 puntos de teoría y 5 de práctica**.
- Microclases animadas y un tutor guiado con explicaciones preparadas.

### Análisis y Diseño

La guía de práctica y el apunte extenso se complementan: una permite comprobar lo aprendido y el otro desarrolla las ideas con más detalle. El recorrido incluye análisis, diseño del sistema, diseño de objetos e interfaces gráficas, con **14 misiones y 54 desafíos cerrados**, además de actividades abiertas.

La configuración del tutor opcional y las instrucciones técnicas están en la [documentación de Análisis y Diseño](estudio-analisis/README.md).

### Python

El curso reúne explicaciones, ejemplos, ejercicios y un proyecto con datos ficticios. El laboratorio usa **Pyodide** para ejecutar Python en el navegador y se carga cuando se necesita. El [plan de estudio](estudio_python/Plan_Python_y_Prompt.md) conserva la planificación original; la implementación actual está en el HTML y en su [módulo de ejecución](estudio_python/pyodide-runner.js).

## Cómo usar los materiales

### Consultar en línea

1. Elegí un recurso en las tablas de este README.
2. Usá **Abrir**, **Leer** o **Acceso rápido** para entrar directamente al material publicado en GitHub Pages.
3. Usá **Ver HTML** si querés consultar el código o descargar el archivo desde GitHub.

Los enlaces públicos de los materiales se pueden compartir sin una cuenta de GitHub. Para estudiar Análisis y Diseño, podés alternar entre el modo práctica y el apunte completo.

### Consultar una copia local

Descargá el repositorio completo desde **Code → Download ZIP** y extraelo, o clonalo:

```sh
git clone https://github.com/d4vdxh1/task-studies.git
cd task-studies
python3 -m http.server 8000
```

Después abrí el recurso que quieras, por ejemplo:

- Kernel Lab: `http://localhost:8000/kernel-lab-info6.html`
- Análisis y Diseño: `http://localhost:8000/guia-interactiva-analisis-diseno.html`
- Apunte completo: `http://localhost:8000/estudio-analisis/apunte-original.html`
- Python: `http://localhost:8000/estudio_python/index.html`

Un servidor HTTP local permite cargar los módulos y procesos de ejecución que algunas guías necesitan. Para la presentación DIESA, conservá su carpeta completa junto con `fuentes`, `logos` y `assets`.

## Alcance y funcionamiento

- **Material educativo.** Las guías y los simulacros son recursos de práctica; no constituyen exámenes oficiales. Los casos de empresas se presentan con fines académicos.
- **Progreso local.** Las guías que guardan avance lo hacen en el navegador. Ese progreso no se sincroniza automáticamente entre dispositivos; usá la exportación cuando esté disponible.
- **Conexión a internet.** Linux real, videos, el intérprete de Pyodide y los recursos servidos desde CDN requieren conexión al cargarse. Lactolanda y el visor del esquema de petróleo también usan dependencias externas. Descargar un HTML no garantiza que todas sus funciones trabajen sin internet.
- **Tutor de Kernel Lab.** Usa explicaciones preparadas y funciona sin una API de IA conectada.
- **Tutor opcional de Análisis y Diseño.** Requiere un servidor configurado por separado. Los ejercicios y sus explicaciones funcionan sin esa integración; GitHub Pages aloja la parte estática.
